saludo.py Ver el repositorio

Un saludo desde la terminal, con validación incluida.

Escribe un nombre y obtén un saludo. Si lo dejas vacío, el programa se detiene con un error claro y devuelve el código de salida 1. Esta página es una prueba y el ejemplo de la derecha reproduce la misma lógica que saludo.py.

python saludo.py Henry
demo en vivoejemplo
¡Hola, Henry!
código de salida: 0

Quita los espacios

Si escribes " Ana ", el saludo sale como ¡Hola, Ana! sin espacios sobrantes.

Rechaza lo vacío

Un nombre en blanco lanza ValueError y el CLI lo muestra en stderr.

Códigos de salida

0 si todo salió bien y 1 si falta el argumento o el nombre no es válido.
